# User Flows — DesignLabs Portfolio

---

## Flow 1: New Visitor Exploring the Portfolio

**Goal:** A potential client lands on the site, gets impressed, and reaches out.

1. **Landing (Hero Section)**
   - User arrives at the homepage
   - Sees headline, tagline, and a prominent CTA ("View My Work")
   - Background visual / animation grabs attention

2. **Scroll → Projects Section**
   - User scrolls down or clicks "View My Work"
   - Sees a curated grid of 3–4 featured projects
   - Each card shows: thumbnail, project name, tags (Branding, UI/UX, Web)

3. **Project Detail (optional click)**
   - User clicks a project card
   - Expands or navigates to a detail view with:
     - Full-width hero image
     - Problem → Solution → Result narrative
     - Tools used, timeline, role
   - CTA at bottom: "Next Project" or "Back to All Work"

4. **Scroll → Skills / Why Work With Me**
   - User continues scrolling
   - Sees skills bento grid and testimonials or value propositions
   - Builds trust and credibility

5. **Scroll → CTA Footer**
   - User reaches the bottom
   - Sees a clear call-to-action: "Let's Work Together"
   - Clicks → opens email, contact form, or Calendly link

**Success metric:** User clicks the final CTA or sends a message.

---

## Flow 2: Recruiter Evaluating Skills & Experience

**Goal:** A recruiter quickly assesses capabilities and downloads a resume or makes contact.

1. **Landing (Hero Section)**
   - Recruiter arrives via a shared link or LinkedIn
   - Immediately sees name, title, and a short professional summary

2. **Navigate → Skills Section**
   - Recruiter clicks "Skills" in the navbar (or scrolls)
   - Sees a structured breakdown:
     - Design: Figma, Adobe Suite, Prototyping
     - Development: React, Next.js, Tailwind, TypeScript
     - Other: Motion design, Design systems, Accessibility

3. **Navigate → Experiments Section**
   - Recruiter clicks "Experiments" in the navbar
   - Sees side projects, open-source contributions, or creative explorations
   - Each entry shows: title, short description, link to demo/repo

4. **Quick Scan → Projects Section**
   - Recruiter glances at project thumbnails for visual quality
   - May click one to confirm depth of work

5. **CTA Footer → Contact / Resume**
   - Recruiter scrolls to footer
   - Options available:
     - "Download Resume" (PDF)
     - "Email Me"
     - LinkedIn / GitHub profile links

**Success metric:** Recruiter downloads resume or initiates contact.
